# Florist

A beautiful, modern florist website with shopping cart functionality. Built with HTML, CSS, and JavaScript as a Progressive Web App.

## Installation

1. Clone or download the project
```bash
git clone https://github.com/Isaac-Kingsley007/Florist.git
```
2. Open Project Folder
```bash
cd Florist
```

3. Open `index.html` in your browser

4. To run as PWA (optional)

```bash
npx serve
```
Then open `http://localhost:3000` in your browser.

5. Open App in your brower
```bash
http://localhost:8000
```
(When using npx serve, the URL may be shown in the terminal.)
